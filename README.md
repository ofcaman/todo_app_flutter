# Todo App (Flutter)

This is my first Todo App built using Flutter and Dart.  
I created this project while following a YouTube tutorial to learn the basics of Flutter development.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean UI

## Technologies Used
- Flutter
- Dart

## Learning Outcome
Through this project, I learned:
- Basic Flutter widgets
- UI layout design
- State management basics
- Building a simple mobile application
